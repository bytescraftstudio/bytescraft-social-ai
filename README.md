## 🌟 Core Features

- **⚡ Autonomous AI Content Engine:** Automatically generates platform-optimized copy for LinkedIn, Instagram, and Facebook targeting BytesCraft Studio's core software engineering services.
- **🎨 Visual Graphic Canvas Designer:** High-resolution HTML5 Canvas rendering engine with dark cyberpunk and neon gradients, service badges, watermarks, and 1-click graphic downloads.
- **📱 Multi-Platform Feed Simulator:** Interactive previews replicating real-world LinkedIn, Instagram, and Facebook feeds with live publishing triggers.
- **📡 Multi-Channel API Publisher:** Native integration ready for Meta Graph API (Facebook Pages & Instagram Professional accounts) and LinkedIn UGC API, backed with robust simulation fallbacks.
- **📊 Real-Time Queue & Analytics Dashboard:** Scheduled queue manager, publishing history logs, and instant post republishing.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Lucide React, HTML5 Canvas API
- **Styling:** Custom Cyberpunk & Glassmorphism Design System (Vanilla CSS tokens)
- **CI/CD:** GitHub Actions Automated Build & Verification
- **Deployment:** Vercel Global Edge Network with SPA rewrite routing

## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/bytescraftstudio/bytescraft-social-ai.git
   cd bytescraft-social-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
